# Standardize on User Visual State and Morph Mode Terminology

To prevent misleading claims in the codebase and maintain domain precision, we will strictly use the term "User Visual State" rather than "cognitive state", "attention state", or "visual state" in all code variables, comments, and schemas. Similarly, we will refer to the UI layout states as "Morph Modes" (such as "Focus Reading Morph Mode") instead of generic "UI Modes" or "display modes" to align with the library's core identity of morphing layout structures.
