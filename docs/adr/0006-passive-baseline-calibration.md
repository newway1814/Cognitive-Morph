# Use Passive Baseline Calibration

To provide a seamless, non-intrusive onboarding experience, we will use passive baseline calibration instead of active user-prompted calibration steps. When the webcam is enabled, the system will silently analyze the user's natural reading patterns (eye movement velocity, blink rate, head tilt, and eye aperture) for the first 10 seconds of interaction to calculate baseline thresholds using moving averages.
